HOW TO CHANGE PHONE PICTURES
============================

Put your own photos in this folder (public/images) using these exact names:

  phone-1.jpg   Vivo V29
  phone-2.jpg   Vivo Y36
  phone-3.jpg   Vivo X100
  phone-4.jpg   Oppo Reno 11
  phone-5.jpg   Oppo A78
  phone-6.jpg   Oppo Reno 10
  phone-7.jpg   Infinix Note 40
  phone-8.jpg   Infinix Hot 40 Pro
  phone-9.jpg   Infinix Zero 30
  phone-10.jpg  iPhone 13
  phone-11.jpg  iPhone 14
  phone-12.jpg  iPhone 15 Pro
  phone-13.jpg  Tecno Spark 20 Pro
  phone-14.jpg  Tecno Camon 30
  phone-15.jpg  Tecno Pova 6 Pro

The photo automatically replaces the drawing on every page: phone cards,
detail page, cart, brand cards and the home banner.
If a file is missing, the drawn phone is shown instead.

Tips:
- Use .jpg (lowercase). Portrait or square photos (about 600x700 px) look best.
- Keep each file under 300 KB so the site loads fast.
- If you add the file while the site is running, refresh the page (Ctrl + F5).
- The numbers match the "id" values in src/data/phones.js.
